# 📝 FreeCodeCamp Desserts Shopping Cart

Une mini application web qui simule un panier d'achat pour différents desserts. Les utilisateurs peuvent ajouter des desserts au panier, voir le total avec taxes et supprimer tous les articles si nécessaire.

## 🚀 Fonctionnalités

- Ajouter des desserts au panier en cliquant sur "Add to cart"
- Afficher/Masquer le panier avec le bouton dédié
- Affichage du nombre d'articles, du sous-total, des taxes et du total
- Supprimer tous les articles du panier avec confirmation

## ⚙️ Prérequis

- Navigateur web moderne
- Connaissance basique de HTML, CSS et JavaScript

## 📂 Structure du projet
desserts-shopping-cart/  
│── index.html      # Structure principale de la page avec header, boutons et conteneurs pour le panier et les desserts  
│── styles.css      # Styles de mise en page, cartes des desserts et design du panier  
│── script.js       # Gestion du panier : ajout d'articles, calcul des totaux, affichage dynamique  
│── README.md       # Documentation du projet  

## 🛠️ Technologies utilisées

HTML5 – Structure de la page  
CSS3 – Mise en forme et design des cartes et du panier  
JavaScript – Gestion du panier, calcul dynamique et DOM manipulation  

## 🎯 Objectif pédagogique

Ce projet illustre l’utilisation de JavaScript pour :  

- Manipuler le DOM et ajouter dynamiquement des éléments  
- Gérer un état local (panier) et effectuer des calculs en temps réel  
- Réagir aux événements utilisateurs (clics sur boutons)
