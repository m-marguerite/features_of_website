# 📝 Real Time Character Counter

Une application web simple qui permet de compter en temps réel le nombre de caractères saisis dans une zone de texte, avec un avertissement lorsque la limite maximale est atteinte.

## 🚀 Fonctionnalités

- Compteur de caractères en temps réel
- Limite maximale de 50 caractères avec alerte si dépassée
- Changement de couleur du compteur lorsque la limite est atteinte
- Design responsive et esthétique

## ⚙️ Prérequis

- Navigateur web moderne (Chrome, Firefox, Edge, Safari)
- Connaissances de base en HTML, CSS et JavaScript pour modification

## 📂 Structure du projet
real-time-counter/  
│── index.html      # Contient la structure de la page et la zone de texte  
│── styles.css      # Définit le style de la page, design responsive et transitions  
│── script.js       # Gère l'interactivité et le compteur de caractères en temps réel  
│── README.md       # Documentation  

## 🛠️ Technologies utilisées

HTML5 – Structure de la page  
CSS3 – Mise en forme, responsive design et transitions  
JavaScript – Gestion du compteur de caractères et interactions utilisateur

## 🎯 Objectif pédagogique

Ce projet illustre l'utilisation de JavaScript pour manipuler le DOM en temps réel et gérer les événements utilisateur.  
Il montre également comment combiner CSS pour le style et les transitions pour une interface agréable.
