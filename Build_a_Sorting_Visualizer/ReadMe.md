# 📝 Sorting Visualizer

Une application web qui permet de générer un tableau aléatoire et de visualiser le tri à bulles (Bubble Sort) étape par étape. Chaque étape du tri est représentée par un conteneur visuel et les éléments comparés sont surlignés pour suivre l'évolution du tri.

## 🚀 Fonctionnalités

- Génération d'un tableau aléatoire d'entiers.
- Visualisation du tri à bulles avec mise en évidence des éléments comparés.
- Ajout d'étapes intermédiaires pour chaque échange effectué.
- Indication du tableau final trié avec un conteneur vert.

## ⚙️ Prérequis

- Navigateur web moderne (Chrome, Firefox, Edge…)
- Compréhension basique de JavaScript pour manipuler le DOM.

##  📂 Structure du projet
sorting-visualizer/  
│── index.html      # Contient la structure de la page et les boutons de contrôle  
│── styles.css      # Définit le style des tableaux et des boutons, responsive design  
│── script.js       # Gère la génération du tableau, le tri à bulles et la visualisation  
│── README.md       # Documentation  

##  🛠️ Technologies utilisées

HTML5 – Structure de la page et éléments interactifs  
CSS3 – Mise en forme, flexbox, responsive design  
JavaScript – Manipulation du DOM et animation du tri

##  🎯 Objectif pédagogique

Ce projet illustre comment manipuler le DOM pour créer des animations interactives et visualiser des algorithmes. Il permet de comprendre la logique du tri à bulles et la mise à jour dynamique des éléments HTML.
