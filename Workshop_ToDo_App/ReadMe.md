# 📝 Todo App

Une application de gestion de tâches simple utilisant **localStorage** pour stocker et récupérer les données côté client. L'utilisateur peut ajouter, modifier et supprimer des tâches avec un formulaire interactif.

## 🚀 Fonctionnalités

- Ajouter une nouvelle tâche avec un titre, une date et une description.
- Modifier une tâche existante.
- Supprimer une tâche.
- Confirmer la fermeture du formulaire si des modifications non enregistrées existent.
- Sauvegarde automatique des tâches dans le localStorage pour persistance.

## ⚙️ Prérequis

- Navigateur moderne supportant **localStorage**.
- Connaissances de base en HTML, CSS et JavaScript.

##  📂 Structure du projet
todo-app/

│── script.js       # Gestion de l'interactivité et stockage local

##  🛠️ Technologies utilisées

HTML5 – Structure de la page  
CSS3 – Mise en forme et design  
JavaScript – Interactivité, manipulation du DOM et localStorage  

##  🎯 Objectif pédagogique

Ce projet illustre l’utilisation de **JavaScript pour manipuler le DOM et interagir avec le localStorage**. Il met en pratique la gestion d’états, l’ouverture/fermeture de formulaires, et la gestion d’événements utilisateur.
