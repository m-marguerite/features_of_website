# 📖 Présentation

Ce repository documente mon apprentissage du **JavaScript** dans le cadre du cursus proposé par freeCodeCamp.
Chaque dossier correspond à un exercice ou un mini projet permettant de pratiquer les concepts suivants :

- manipulation du DOM
- gestion des événements utilisateurs
- animations et transitions CSS/JS
- filtrage et affichage dynamique de données
- interactions avancées avec l'interface utilisateur

---

# 🎯 Objectifs pédagogiques

Ce projet a pour but de :

- Comprendre et manipuler le **DOM** avec JavaScript
- Gérer les **événements** clavier, souris et formulaires
- Créer des **interfaces interactives** sans framework
- Pratiquer les **animations** CSS et JavaScript
- Structurer des mini projets front-end de manière claire et organisée
