# 📝 Visualisation Récursion – Range of Numbers Generator

Application web interactive permettant de visualiser le fonctionnement d’une fonction récursive qui génère un tableau de nombres entre deux valeurs.


## 🚀 Fonctionnalités

- Génération d’un tableau de nombres entre deux valeurs
- Implémentation d’une fonction récursive pure en JavaScript
- Affichage dynamique des résultats sous forme de cartes
- Animation progressive pour visualiser la “construction” du tableau
- Validation des entrées utilisateur


## ⚙️ Prérequis

- Navigateur web moderne (Chrome, Firefox, Edge…)
- JavaScript activé


## 📂 Structure du projet

visualisation-recursion/  
│── index.html      # Structure HTML et interface utilisateur  
│── styles.css      # Mise en forme, cartes visuelles et responsive  
│── script.js       # Logique récursive et manipulation du DOM  
│── README.md       # Documentation  


## 🛠️ Technologies utilisées

HTML5 – Structure de la page  
CSS3 – Mise en forme, Flexbox et animations simples  
JavaScript (ES6+) – Récursion, manipulation du DOM, événements  


## 🎯 Objectif pédagogique

Ce projet met en pratique :

- La compréhension du principe de récursion
- La mise en place d’une condition d’arrêt (base case)
- La construction d’un tableau via l’opérateur spread (`...`)
- La manipulation dynamique du DOM
- La validation de données utilisateur
- L’animation simple basée sur l’index pour visualiser un processus logique

Il permet de transformer un exercice algorithmique abstrait en une visualisation concrète et interactive.
