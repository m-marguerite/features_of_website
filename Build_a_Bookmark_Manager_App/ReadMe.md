# 📝 Bookmark Manager

Une application web simple permettant de gérer des bookmarks organisés par catégorie, avec stockage local pour conserver les données entre les sessions.

## 🚀 Fonctionnalités

- Ajouter un bookmark à une catégorie spécifique.  
- Afficher tous les bookmarks d’une catégorie sélectionnée.  
- Supprimer un bookmark existant.  
- Navigation simple entre le menu principal, le formulaire et la liste des bookmarks.  

## ⚙️ Prérequis

- Navigateur moderne (Chrome, Firefox, Edge…) supportant `localStorage`.  
- Aucun serveur requis, fonctionne en local.  

## 📂 Structure du projet

`bookmark-manager/`  
│── index.html      # Structure principale avec sections pour menu, formulaire et liste  
│── styles.css      # Style global, layout, responsive et effets d’interaction  
│── script.js       # Gestion du DOM, stockage local, interactivité des boutons  
│── README.md       # Documentation  

## 🛠️ Technologies utilisées

HTML5 – Structure de la page  
CSS3 – Mise en forme, design et réactivité  
JavaScript – DOM, gestion des événements et stockage local  

## 🎯 Objectif pédagogique

Ce projet illustre l’utilisation de JavaScript pour :  
- Manipuler le DOM de manière dynamique.  
- Travailler avec `localStorage` pour la persistance des données.  
- Gérer des événements utilisateur et la navigation entre plusieurs sections d’une page.
